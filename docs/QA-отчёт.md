## Найденные и исправленные ошибки при восстановлении

1. **Клавиатуры бота шли мимо Bot API.** Черновик карточки передавал
   `inline_keyboard` верхнеуровнево, а Telegram ждёт его внутри `reply_markup`.
   Поймано тестом «у карточки есть кнопки confirm»; исправлено в
   `_shared/telegram.ts`.
2. **`todayISO` отсутствовал среди экспортов** `_shared/telegram.ts` — вебхук
   импортировал несуществующее имя. Ловится на этапе загрузки модуля.
3. **Импорт `SupabaseClient` без `type`** в `_shared/supabase.ts` — рантайм
   требовал значение из модуля, где есть только тип. Исправлено на
   `import { createClient, type SupabaseClient }`.
4. **Дайджест молчал при проверке лимитов**, если за прошедшую неделю не было
   операций, — сценарий разделил «нет операций» и «есть что показать»; теперь
   тест засеивает операции обеих недель.
5. **Повторные напоминания** — проверено, что пометка `reminderMarks` блокирует
   вторую отправку того же платежа (тест «повторный запуск не дублирует»).

## Проверки, которые важнее остальных

- **Защита от потери данных.** `tests/unit.mjs`: при `sync.state=error`
  `upsertOp` возвращает `null`, операция не попадает в память; в
  `tests/smoke.mjs` баннер сообщает о блокировке записи. Это тест той самой
  ошибки версии 1.0, из-за которой «пропадали данные».
- **Копейки и даты.** `sumMoney` не накапливает ошибку плавающей точки;
  `addMonthsISO('2026-01-31', 1) === '2026-02-28'` — сдвига дат из-за UTC нет.
- **Независимая проверка ZIP.** Тест разбирает архив вручную (EOCD →
  центральный каталог) и сверяет CRC32 каждого файла с `zlib.crc32` — кодом
  вне приложения.
- **Учёт только в рублях.** Профиль со старой валютой `PLN` и курсами
  приводится к `RUB`, курсы удаляются (проверено по `profile.json` из архива),
  символы `zł/€/$` убираются из импорта с предупреждением.
- **Бот пишет в базу только после подтверждения** и только в привязанный
  аккаунт; чужие операции в отчёты не попадают (RLS-стаб фильтрует по
  `user_id`).
- **Отказы.** 401 без JWT, 403 без секрета вебхука/CRON, 429 при превышении
  лимита ai-parse, 413 на больших аудио/фото — по каждому есть тест.

## Ограничения

- E2E в настоящем Chrome выполняется в CI (GitHub Actions ставит Chrome);
  локально без Chrome набор пропускается сообщением, а не падением.
- Интеграцию с живым Supabase/Telegram тесты эмулируют стабами: реальный
  вебхук, JWT и RLS стоит один раз проверить руками по чек-листу из
  `supabase/functions/README.md` (секрет вебхука, миграции, Realtime).
