# Changelog

## 3.0.0 — Personal OS

Полная переработка интерфейса. Данные Supabase и Telegram-бот сохранены.

### Добавлено
- Новое приложение на React + TypeScript + Vite + Tailwind: десктопный сайдбар, мобильная нижняя навигация, PWA.
- Главная с настраиваемыми блоками, экран «Сегодня», глобальный поиск (Ctrl/⌘ + K), внутренние уведомления и уведомления браузера.
- Финансы: операции, повторяющиеся платежи, финансовый календарь, прогноз на 3/6/12/24 месяца, лимиты по категориям.
- Долги: история платежей с отменой, калькулятор погашения.
- Авто: несколько машин, заправки, ремонты, расходы, напоминания по дате и пробегу; автокалькулятор и сравнение; What-if.
- Цели, задачи (повторяющиеся), обучение (треки и темы), заметки (теги, закрепление), IT-команды с копированием.
- Умный ввод «+1200 бензин» с подтверждением; заготовка AI-модуля.
- Экспорт CSV/JSON, «Export all data», опасная зона с подтверждением.
- Миграция `202610020001_personal_os.sql` (additive, с резервной копией `legacy_profile_backup`).
- GitHub Actions: lint → typecheck → test → build → deploy на GitHub Pages.

### Изменено
- Кредиты, карты, повторяющиеся платежи и цели в `finance_profiles` теперь строятся из новых таблиц триггерами — бот видит актуальные данные.

### Удалено
- Старое одностраничное приложение (`index.html` на чистом JS, демо, Service Worker, сборщик `build.mjs`). История — в `docs-CHANGELOG-legacy.md`.
